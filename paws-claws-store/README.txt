=== PAWS & CLAWS EMPORIUM - XAMPP SETUP GUIDE ===
1. Extract this folder into: C:\xampp\htdocs\paws-claws-store
2. Open XAMPP Control Panel and start 'Apache' and 'MySQL'.
3. Open your browser and go to: http://localhost/phpmyadmin
4. Click 'Import' at the top, choose the file 'database.sql' from inside this folder, and click 'Import'.
5. Open your store in the browser: http://localhost/paws-claws-store/
6. Open your Admin Control Panel: http://localhost/paws-claws-store/admin/
   - Default Username: admin
   - Default Password: admin123
7. Inside Admin -> Settings, paste your real Stripe Keys and PayPal Client ID whenever you are ready to accept real money!
